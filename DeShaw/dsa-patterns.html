Hashing & Frequency Counting

Definition — Store values, counts, or a computed key of each element in a hash map or set so membership, frequency, and complement lookups drop from an O(n) scan to O(1) average time.

When to use it — Any time the brute-force approach is "for each element, scan the rest of the array to check something" — duplicate detection, complement search (target − x), grouping by a transformed key, or tallying occurrences.

Core data structures — hash maphash setarray-as-hash (index encoding)

EASY

Two Sum

LC 1

Given an array of integers and a target, return the indices of the two numbers that add up to the target.

Why this pattern — Scan once, storing each seen value's index in a map. For every new number, check whether its complement is already a key — one pass replaces the nested-loop search.

def twoSum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        complement = target - n
        if complement in seen:
            return [seen[complement], i]
        seen[n] = i
    return []

Time O(n) · Space O(n)

MEDIUM

Group Anagrams

LC 49

Group an array of strings into lists where every string in a group is an anagram of the others.

Why this pattern — Two strings are anagrams exactly when their 26-length letter-count signature is identical, so that signature (as a tuple) becomes the hash-map key that buckets every word in a single pass.

def groupAnagrams(strs):
    groups = collections.defaultdict(list)
    for s in strs:
        key = [0] * 26
        for ch in s:
            key[ord(ch) - ord('a')] += 1
        groups[tuple(key)].append(s)
    return list(groups.values())

Time O(n·k) (k = avg word length) · Space O(n·k)

HARD

First Missing Positive

LC 41

Given an unsorted integer array, find the smallest missing positive integer in O(n) time and O(1) extra space.

Why this pattern — A hash set would solve this trivially but costs O(n) space. Instead, use the array itself as the hash table: place each value v (1≤v≤n) at index v−1 by swapping. The first index whose value doesn't match index+1 reveals the answer — hashing without allocating a hash structure.

def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]
    for i in range(n):
        if nums[i] != i + 1:
            return i + 1
    return n + 1

Time O(n) · Space O(1) extra

PATTERN 02 / 28

Prefix Sum

Definition — Precompute cumulative sums so the sum of any subarray [i, j] is answerable in O(1) via prefix[j+1] − prefix[i], instead of re-summing the range on every query.

When to use it — Repeated range-sum queries on an immutable array, counting subarrays that sum to a target (paired with a hash map of prefix-sum counts), or comparing running totals from the left and right simultaneously.

Core data structures — array (prefix table)hash map (prefix-sum → count/index)

EASY

Range Sum Query — Immutable

LC 303

Given an immutable integer array, implement sumRange(i, j) to be called many times efficiently.

Why this pattern — The textbook case — build a prefix array once where prefix[k] = prefix[k-1] + nums[k-1], and every subsequent query becomes a single subtraction.

class NumArray:
    def __init__(self, nums):
        self.prefix = [0]
        for n in nums:
            self.prefix.append(self.prefix[-1] + n)

    def sumRange(self, i, j):
        return self.prefix[j + 1] - self.prefix[i]

Build O(n) · Query O(1) · Space O(n)

MEDIUM

Subarray Sum Equals K

LC 560

Count the number of contiguous subarrays whose elements sum to exactly k.

Why this pattern — A subarray (i, j] sums to k exactly when prefix[j] − prefix[i] = k, i.e. prefix[i] = prefix[j] − k. Track how many times each running prefix value has occurred in a hash map, so every index answers "how many valid i's exist" in O(1).

def subarraySum(nums, k):
    count = collections.defaultdict(int)
    count[0] = 1
    total = res = 0
    for n in nums:
        total += n
        res += count[total - k]
        count[total] += 1
    return res

Time O(n) · Space O(n)

HARD

Maximum Sum of 3 Non-Overlapping Subarrays

LC 689

Given an array and fixed length k, find three non-overlapping length-k subarrays with the maximum total sum; return their starting indices (smallest lexicographically on ties).

Why this pattern — First build a prefix/window-sum array so every length-k window sum is O(1) to read. Then build left[i] = best single window start in [0,i] and right[i] = best single window start in [i, n-1] from those window sums, and finally scan every valid middle window combining left + mid + right in one pass.

def maxSumOfThreeSubarrays(nums, k):
    n = len(nums)
    window = sum(nums[:k])
    sums = [window]
    for i in range(k, n):
        window += nums[i] - nums[i - k]
        sums.append(window)

    m = len(sums)
    left = [0] * m
    best = 0
    for i in range(m):
        if sums[i] > sums[best]:
            best = i
        left[i] = best

    right = [0] * m
    best = m - 1
    for i in range(m - 1, -1, -1):
        if sums[i] >= sums[best]:
            best = i
        right[i] = best

    result, bestTotal = None, -1
    for mid in range(k, m - k):
        l, r = left[mid - k], right[mid + k]
        total = sums[l] + sums[mid] + sums[r]
        if total > bestTotal:
            bestTotal, result = total, [l, mid, r]
    return result

Time O(n) · Space O(n)

Two Pointers (Opposite Ends)

Definition — Walk two indices toward each other across a sorted or structured sequence, eliminating one side each step based on a comparison, so the search space shrinks linearly instead of quadratically.

When to use it — Sorted-array target sums, palindrome checks, area/container maximization, partitioning — anywhere a nested loop would compare "every pair" but the array's order lets you rule out a whole side at once.

Core data structures — arraystring (two index variables — no extra structure required)

EASY

Valid Palindrome

LC 125

Given a string, determine if it's a palindrome considering only alphanumeric characters and ignoring case.

Why this pattern — Point l at the start and r at the end; skip non-alphanumeric characters on either side, compare what's left, and close inward — a mismatch is an immediate false.

def isPalindrome(s):
    l, r = 0, len(s) - 1
    while l < r:
        while l < r and not s[l].isalnum():
            l += 1
        while l < r and not s[r].isalnum():
            r -= 1
        if s[l].lower() != s[r].lower():
            return False
        l += 1
        r -= 1
    return True

Time O(n) · Space O(1)

MEDIUM

3Sum

LC 15

Find all unique triplets in an array that sum to zero.

Why this pattern — Sort first, fix one number, then run an opposite-ends two-pointer scan on the remainder to find pairs summing to its negation — an O(n³) brute force collapses to O(n²), skipping duplicates at the fixed index and at both pointers.

def threeSum(nums):
    nums.sort()
    res = []
    for i in range(len(nums)):
        if i > 0 and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            total = nums[i] + nums[l] + nums[r]
            if total < 0:
                l += 1
            elif total > 0:
                r -= 1
            else:
                res.append([nums[i], nums[l], nums[r]])
                l += 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1
    return res

Time O(n²) · Space O(1) extra (excluding output)

HARD

Trapping Rain Water

LC 42

Given elevation heights, compute how much rainwater is trapped between the bars.

Why this pattern — Water trapped at index i is min(maxLeft, maxRight) − height[i]. Instead of precomputing both arrays, walk l and r inward and always advance the side with the smaller current max — that side's trapped water is fully determined, because the taller side guarantees a higher ceiling already exists.

def trap(height):
    l, r = 0, len(height) - 1
    leftMax, rightMax = 0, 0
    water = 0
    while l < r:
        if height[l] < height[r]:
            leftMax = max(leftMax, height[l])
            water += leftMax - height[l]
            l += 1
        else:
            rightMax = max(rightMax, height[r])
            water += rightMax - height[r]
            r -= 1
    return water

Time O(n) · Space O(1)

PATTERN 04 / 28

Fast & Slow Pointers

Definition — Advance two pointers through a sequence at different speeds — typically 1 step and 2 steps — so their relative displacement reveals structure: a cycle, its entry point, or a functional-graph collision.

When to use it — Cycle detection in a linked list, finding the middle node without a length pass, or detecting a "duplicate" by treating array values as implicit next-pointers.

Core data structures — linked listarray (as implicit functional graph)

EASY

Linked List Cycle

LC 141

Determine whether a linked list contains a cycle.

Why this pattern — If slow moves 1 node per step and fast moves 2, and a cycle exists, fast eventually laps slow and they occupy the same node; if the list is acyclic, fast simply reaches null first.

def hasCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            return True
    return False

Time O(n) · Space O(1)

MEDIUM

Linked List Cycle II

LC 142

If the list has a cycle, return the node where the cycle begins.

Why this pattern — After slow and fast meet inside the loop, resetting one pointer to head and advancing both one step at a time makes them meet exactly at the cycle's entrance — a direct consequence of the distance algebra between the meeting point and the entry node.

def detectCycle(head):
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
        if slow is fast:
            ptr = head
            while ptr is not slow:
                ptr = ptr.next
                slow = slow.next
            return ptr
    return None

Time O(n) · Space O(1)

HARD

Find the Duplicate Number

LC 287 · hard-tier pick

Given n+1 integers in the range [1, n] with exactly one number repeated (possibly more than once), find it without modifying the array and in O(1) extra space.

Why this pattern — Interpret nums as a linked list where index i points to index nums[i]. Because a value repeats, two different indices point to the same next index — that collision forces a cycle, so Floyd's algorithm finds the duplicate exactly like finding a cycle's entrance.

def findDuplicate(nums):
    slow = fast = nums[0]
    while True:
        slow = nums[slow]
        fast = nums[nums[fast]]
        if slow == fast:
            break
    slow2 = nums[0]
    while slow2 != slow:
        slow2 = nums[slow2]
        slow = nums[slow]
    return slow

Time O(n) · Space O(1)

Sliding Window — Fixed Size

Definition — Maintain a window of constant width k over a sequence; slide it one step at a time, removing the element that falls out the back and adding the one entering the front, updating the running aggregate in O(1) instead of recomputing the whole window.

When to use it — Fixed-length subarray or substring statistics — max, min, or average of every window of size k, anagram-window matching, or windowed maximum with a monotonic deque.

Core data structures — array / string (window bounds)deque (windowed max/min)

EASY

Maximum Average Subarray I

LC 643

Given an array and integer k, find the maximum average value of a contiguous subarray of length k.

Why this pattern — Keep a running sum of the last k elements; each slide subtracts the outgoing element and adds the incoming one, avoiding an O(n·k) re-sum.

def findMaxAverage(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]
        best = max(best, window)
    return best / k

Time O(n) · Space O(1)

MEDIUM

Permutation in String

LC 567

Given strings s1 and s2, determine whether s2 contains a permutation of s1 (a window whose letter counts match s1's).

Why this pattern — The window width is fixed at len(s1); slide it across s2 one character at a time, incrementally updating a 26-length count array (increment the entering character, decrement the one leaving) and comparing to s1's target counts.

def checkInclusion(s1, s2):
    need, window = [0] * 26, [0] * 26
    for ch in s1:
        need[ord(ch) - ord('a')] += 1
    k = len(s1)
    for i, ch in enumerate(s2):
        window[ord(ch) - ord('a')] += 1
        if i >= k:
            out = ord(s2[i - k]) - ord('a')
            window[out] -= 1
        if i >= k - 1 and window == need:
            return True
    return False

Time O(26n) ≈ O(n) · Space O(1)

HARD

Sliding Window Maximum

LC 239

Given an array and window size k, return the maximum of every window of size k as it slides left to right.

Why this pattern — A plain fixed window tracks a sum in O(1), but tracking a max needs a monotonic decreasing deque of indices: pop smaller trailing values before pushing the new one (they can never win again while the new value is in play), and drop the front once it slides out of range. The deque's front is always the current window's max.

def maxSlidingWindow(nums, k):
    dq = collections.deque()
    res = []
    for i, n in enumerate(nums):
        while dq and nums[dq[-1]] < n:
            dq.pop()
        dq.append(i)
        if dq[0] <= i - k:
            dq.popleft()
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

Time O(n) (each index pushed/popped once) · Space O(k)

Sliding Window — Variable Size

Definition — Grow the window by moving the right pointer until a condition breaks or is satisfied, then shrink from the left until it's valid again, tracking the best window seen — the width adapts to the data instead of staying fixed.

When to use it — Longest/shortest substring or subarray satisfying a constraint (no repeats, sum ≥ target), and "best single pass" problems where you track a running minimum or maximum as you extend right.

Core data structures — array / string (two pointers)hash map / set (window contents)

EASY

Best Time to Buy and Sell Stock

LC 121

Given daily prices, maximize profit from one buy followed by one later sell.

Why this pattern — The implicit window is [buy day, sell day]. Walk right through prices tracking the minimum price seen so far — the effective left edge collapses to the cheapest buy point — and at each day compute price − minSoFar as a candidate profit.

def maxProfit(prices):
    minPrice = float('inf')
    best = 0
    for p in prices:
        minPrice = min(minPrice, p)
        best = max(best, p - minPrice)
    return best

Time O(n) · Space O(1)

MEDIUM

Longest Substring Without Repeating Characters

LC 3

Find the length of the longest substring without repeating characters.

Why this pattern — Extend right, recording each character's last-seen index. The moment a repeat appears inside the current window, jump the left pointer past that character's previous occurrence instead of restarting — the window only ever grows or jumps forward, never rescans.

def lengthOfLongestSubstring(s):
    last_seen = {}
    left = 0
    best = 0
    for right, ch in enumerate(s):
        if ch in last_seen and last_seen[ch] >= left:
            left = last_seen[ch] + 1
        last_seen[ch] = right
        best = max(best, right - left + 1)
    return best

Time O(n) · Space O(min(n, alphabet))

Minimum Window Substring

LC 76

Given strings s and t, find the smallest substring of s that contains every character of t (with multiplicity).

Why this pattern — Expand right, adding characters until the window covers all of t's required counts, then greedily contract left as far as possible while it's still valid, recording the smallest valid window seen. A "need" counter plus a single "missing" tally avoids rescanning the window on every check.

def minWindow(s, t):
    if not t or not s:
        return ""
    need = collections.Counter(t)
    missing = len(t)
    left = start = end = 0
    for right, ch in enumerate(s, 1):
        if need[ch] > 0:
            missing -= 1
        need[ch] -= 1
        if missing == 0:
            while need[s[left]] < 0:
                need[s[left]] += 1
                left += 1
            if end == 0 or right - left < end - start:
                start, end = left, right
            need[s[left]] += 1
            missing += 1
            left += 1
    return s[start:end]

Time O(n + m) · Space O(alphabet)

Monotonic Stack

Definition — Maintain a stack whose elements stay strictly increasing or decreasing from bottom to top by popping every element that violates the order before pushing the new one — each pop marks that a "next greater/smaller" answer was just found for the popped element.

When to use it — Next-greater/smaller element queries, "wait until warmer" style problems, and largest-rectangle style area problems where you need, for every element, the nearest smaller element on each side.

Core data structures — stack (holding values or indices)

EASY

Next Greater Element I

LC 496

For each element of nums1 (a subset of nums2), find its next greater element to the right in nums2, or −1 if none exists.

Why this pattern — Scan nums2 once with a decreasing stack of values. Whenever the current number beats the stack's top, that top just found its next-greater — pop it, record the mapping, then push the current number.

def nextGreaterElement(nums1, nums2):
    next_greater = {}
    stack = []
    for n in nums2:
        while stack and stack[-1] < n:
            next_greater[stack.pop()] = n
        stack.append(n)
    return [next_greater.get(n, -1) for n in nums1]

Time O(n + m) · Space O(n)

MEDIUM

Daily Temperatures

LC 739

For each day, find how many days must pass until a warmer temperature; 0 if never.

Why this pattern — Keep a stack of indices with decreasing temperatures. When today beats the temperature at the index on top, that index's wait is today − index days — pop and record it, repeating until the top is warmer than today or the stack empties.

def dailyTemperatures(temperatures):
    res = [0] * len(temperatures)
    stack = []
    for i, t in enumerate(temperatures):
        while stack and temperatures[stack[-1]] < t:
            j = stack.pop()
            res[j] = i - j
        stack.append(i)
    return res

Time O(n) · Space O(n)

Largest Rectangle in Histogram

LC 84

Given bar heights, find the area of the largest rectangle that fits within the histogram.

Why this pattern — The widest rectangle a bar can anchor spans from the first shorter bar on its left to the first shorter bar on its right. An increasing stack of indices finds exactly that: when a shorter bar arrives, pop the stack computing each popped bar's area using the new bar as its right boundary and the newly-exposed stack top as its left boundary.

def largestRectangleArea(heights):
    stack = []
    best = 0
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] >= h:
            height = heights[stack.pop()]
            width = i if not stack else i - stack[-1] - 1
            best = max(best, height * width)
        stack.append(i)
    return best

Time O(n) · Space O(n)

Modified Binary Search

Definition — Repeatedly halve a sorted (or "sorted enough" — rotated, bitonic) range by comparing the midpoint against a condition, discarding the half that can't contain the answer, so the search runs in O(log n) instead of O(n).

When to use it — Searching a sorted or rotated-sorted array, finding a boundary or first/last occurrence, or any structure where one comparison at the midpoint tells you which half to keep.

Core data structures — array (sorted or rotated-sorted)

EASY

Binary Search

LC 704

Given a sorted array and a target, return its index or −1.

Why this pattern — The vanilla case: compare the target to the midpoint and discard the half that can't contain it.

def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        elif nums[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

Time O(log n) · Space O(1)

MEDIUM

Search in Rotated Sorted Array

LC 33

Search for a target in a rotated sorted array (rotated at an unknown pivot) in O(log n).

Why this pattern — At every midpoint, one half — left-to-mid or mid-to-right — is still normally sorted even though the whole array isn't. Determine which half is sorted, check whether the target lies inside that sorted half's range, and discard accordingly — the same halving logic with one extra branch.

def search(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target:
            return mid
        if nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else:
                lo = mid + 1
        else:
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else:
                hi = mid - 1
    return -1

Time O(log n) · Space O(1)

HARD

Median of Two Sorted Arrays

LC 4

Given two sorted arrays, find the median of the combined array in O(log(min(m, n))) time.

Why this pattern — Binary search on the partition point of the smaller array instead of on values. For a candidate partition i in array A, the matching partition j in B is fixed by the target left-half size. Halve on i until maxLeftA ≤ minRightB and maxLeftB ≤ minRightA, which certifies a valid overall partition — the median then reads directly off the four boundary values.

def findMedianSortedArrays(A, B):
    if len(A) > len(B):
        A, B = B, A
    m, n = len(A), len(B)
    lo, hi = 0, m
    while lo <= hi:
        i = (lo + hi) // 2
        j = (m + n + 1) // 2 - i
        Aleft  = A[i - 1] if i > 0 else float('-inf')
        Aright = A[i]     if i < m else float('inf')
        Bleft  = B[j - 1] if j > 0 else float('-inf')
        Bright = B[j]     if j < n else float('inf')
        if Aleft <= Bright and Bleft <= Aright:
            if (m + n) % 2 == 1:
                return max(Aleft, Bleft)
            return (max(Aleft, Bleft) + min(Aright, Bright)) / 2
        elif Aleft > Bright:
            hi = i - 1
        else:
            lo = i + 1

Time O(log(min(m, n))) · Space O(1)

PATTERN 09 / 28

Binary Search on the Answer

Definition — When the answer lives in a monotonic range (if value X works, every value beyond X also works), binary search over candidate answers rather than array indices — check feasibility at the midpoint with a helper function and shrink the range accordingly.

When to use it — "Minimize the maximum" or "maximize the minimum" problems — smallest capacity that still finishes in time, largest minimum distance — especially when no closed-form formula exists but a feasibility check does.

Core data structures — none beyond the input array fed to a feasibility check — the search structure is the answer's own value range

EASY

Sqrt(x)

LC 69

Given a non-negative integer x, return floor(√x) without using a built-in power function.

Why this pattern — The answer space [0, x] is monotonic — if k·k ≤ x, every value below k also satisfies it, and above k it fails. Binary search that boundary directly instead of scanning up from 0.

def mySqrt(x):
    lo, hi = 0, x
    ans = 0
    while lo <= hi:
        mid = (lo + hi) // 2
        if mid * mid <= x:
            ans = mid
            lo = mid + 1
        else:
            hi = mid - 1
    return ans

Time O(log x) · Space O(1)

MEDIUM

Koko Eating Bananas

LC 875

Koko eats at speed k bananas/hour from piles of bananas; find the minimum integer k so she finishes all piles within h hours.

Why this pattern — As k increases, the total hours needed only decreases — monotonic. Binary search k over [1, max(piles)], and for each candidate run an O(n) feasibility check (sum of ceil(pile / k)) to decide which half of the speed range to keep.

def minEatingSpeed(piles, h):
    lo, hi = 1, max(piles)
    while lo < hi:
        k = (lo + hi) // 2
        hours = sum((p + k - 1) // k for p in piles)
        if hours <= h:
            hi = k
        else:
            lo = k + 1
    return lo

Time O(n·log(max(piles))) · Space O(1)

HARD

Split Array Largest Sum

LC 410

Split an array into m contiguous subarrays to minimize the largest subarray sum.

Why this pattern — The answer space is "largest allowed subarray sum," ranging from max(nums) to sum(nums), and it's monotonic — a larger cap always makes it at least as easy to fit into m subarrays. def splitArray(nums, m):
    def subarrays_needed(cap):
        count, current = 1, 0
        for n in nums:
            if current + n > cap:
                count += 1
                current = n
            else:
                current += n
        return count

    lo, hi = max(nums), sum(nums)
    while lo < hi:
        cap = (lo + hi) // 2
        if subarrays_needed(cap) <= m:
            hi = cap
        else:
            lo = cap + 1
    return lo

        for ch in word:
            node = node.children.setdefault(ch, TrieNode())

        return node

    cols, diag1, diag2 = set(), set(), set()   # diag1: r-c, diag2: r+c
    board = [["."] * n for _ in range(n)]

    def backtrack(r):
        if r == n:
            res.append(["".join(row) for row in board])
            return
        for c in range(n):
            if c in cols or (r - c) in diag1 or (r + c) in diag2:
                continue
            cols.add(c); diag1.add(r - c); diag2.add(r + c)
            board[r][c] = "Q"
            backtrack(r + 1)
            board[r][c] = "."
            cols.discard(c); diag1.discard(r - c); diag2.discard(r + c)

    backtrack(0)
    return res

Merge Intervals

Definition — Sort intervals by start time, then sweep left to right, merging any interval that overlaps the current merged interval (its start ≤ the current merged end) by extending the end — turns pairwise overlap checking into a single linear sweep after one sort.

When to use it — Merging overlapping meeting times or ranges, inserting a new interval into a sorted set, and scheduling or room-allocation questions.

Core data structures — array (sorted by start)heap (for "currently active" interval ends, in sweep variants)

Summary Ranges

LC 228

Given a sorted, unique array of integers, return the smallest sorted list of ranges that exactly covers every number.

Why this pattern — Walk the sorted array extending the current range as long as the next number is exactly one more than the last — i.e. "adjacent" — closing the range and starting a new one the moment a gap appears. The same sweep-and-extend logic as interval merging, applied to implicit unit-width intervals.

def summaryRanges(nums):
    if not nums:
        return []
    res = []
    start = nums[0]
    for i in range(1, len(nums) + 1):
        if i == len(nums) or nums[i] != nums[i-1] + 1:
            end = nums[i-1]
            res.append(str(start) if start == end else f"{start}->{end}")
            if i < len(nums):
                start = nums[i]
    return res

Time O(n) · Space O(1) extra (excluding output)

Merge Intervals

LC 56

Given a collection of intervals, merge all overlapping intervals.

Why this pattern — Sort by start time, then sweep through: whenever the next interval's start is ≤ the current merged interval's end, they overlap — extend the current merged end to the max of both; otherwise close the current merged interval and open a new one.

def merge(intervals):
    intervals.sort(key=lambda iv: iv[0])
    merged = [intervals[0]]
    for start, end in intervals[1:]:
        if start <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], end)
        else:
            merged.append([start, end])
    return merged

Time O(n log n) (sort dominates) · Space O(n)

HARD

Minimum Interval to Include Each Query

LC 1851

Given a list of intervals and a list of query points, for each query find the size of the smallest interval containing it, or −1 if none does.

Why this pattern — Sort both intervals and queries. Sweep queries in increasing order, pushing every interval whose start has come into play onto a min-heap keyed by interval size, and lazily popping intervals whose end has already passed the current query. The heap's top is always the smallest still-valid interval — the interval-sweep idea combined with a heap for "smallest that still covers me."

def minInterval(intervals, queries):
    intervals.sort()
    sorted_queries = sorted(range(len(queries)), key=lambda i: queries[i])
    heap = []
    res = [-1] * len(queries)
    i = 0
    for q_idx in sorted_queries:
        q = queries[q_idx]
        while i < len(intervals) and intervals[i][0] <= q:
            start, end = intervals[i]
            heapq.heappush(heap, (end - start + 1, end))
            i += 1
        while heap and heap[0][1] < q:
            heapq.heappop(heap)
        if heap:
            res[q_idx] = heap[0][0]
    return res

Time O((n + m) log(n + m)) · Space O(n)

Bit Manipulation

Definition — Operate directly on a number's binary representation with AND, OR, XOR, NOT, and shifts to extract, set, clear, or toggle individual bits — exploiting identities like "XOR cancels duplicate pairs" or "AND with (n−1) clears the lowest set bit" to solve problems in O(1) or O(bit-width) instead of allocating extra structures.

When to use it — Finding a single non-duplicate among duplicates, counting set bits, detecting powers of two, and combinatorial problems where a bitmask compactly represents a subset.

Core data structures — integer (as a bit array), sometimes a bitwise trie

EASY

Single Number

LC 136

Given an array where every element appears twice except one, find that single element.

Why this pattern — XOR-ing every number together cancels every pair to 0 (x⊕x=0) and leaves only the unpaired value, since XOR is commutative, associative, and self-cancelling — no hash set required.

def singleNumber(nums):
    result = 0
    for n in nums:
        result ^= n
    return result

Time O(n) · Space O(1)

MEDIUM

Single Number II

LC 137

Given an array where every element appears three times except one, find that single element.

Why this pattern — Track each bit position's count modulo 3 across all numbers using two accumulator variables that cycle bit-states 0→1→2→0 as each number folds in — a bit survives in the final result only if its true count mod 3 is 1, exactly the position the singleton holds.

def singleNumber(nums):
    ones, twos = 0, 0
    for n in nums:
        ones = (ones ^ n) & ~twos
        twos = (twos ^ n) & ~ones
    return ones

Time O(n) · Space O(1)

HARD

Maximum XOR of Two Numbers in an Array

LC 421 · hard-tier pick

Given an array of integers, find the maximum XOR of any two numbers in the array.

Why this pattern — Build a binary trie of every number's bits, most-significant-bit first. For each number, greedily walk the trie trying the opposite-bit branch at every level — safe because a higher bit always contributes more to the XOR result than every lower bit combined — a direct bitwise application of the trie pattern.

def findMaximumXOR(nums):
    root = {}
    for n in nums:
        node = root
        for i in range(31, -1, -1):
            bit = (n >> i) & 1
            node = node.setdefault(bit, {})

    best = 0
    for n in nums:
        node = root
        curr_xor = 0
        for i in range(31, -1, -1):
            bit = (n >> i) & 1
            toggled = 1 - bit
            if toggled in node:
                curr_xor |= (1 << i)
                node = node[toggled]
            else:
                node = node[bit]
        best = max(best, curr_xor)
    return best

Time O(32n) · Space O(32n)

Cyclic Sort & Matrix Traversal

Matrix Traversal patterns (spiral, layer-by-layer, transpose+reverse) systematically visit or rearrange grid cells using boundary pointers or direction vectors.

When to use it — Finding missing/duplicate numbers in a bounded-range array, and printing or rotating a matrix in a specific geometric order.

Core data structures — array (in-place index manipulation)boundary pointers (top/bottom/left/right)

EASY

Missing Number

LC 268

Given an array containing n distinct numbers from the range [0, n], find the one missing number.

Why this pattern — The cyclic-sort idea in its simplest form: instead of physically swapping each value to its index, compare the expected sum of [0, n] against the actual sum — the gap is the missing number. A full swap-based cyclic sort (placing each value v at index v) solves it too; this is the cleanest realization of "a known bounded range means no extra structure is needed."

def missingNumber(nums):
    n = len(nums)
    expected = n * (n + 1) // 2
    return expected - sum(nums)

Time O(n) · Space O(1)

MEDIUM

Spiral Matrix

LC 54

Given an m×n matrix, return all its elements in spiral order.

Why this pattern — Maintain four boundary pointers — top, bottom, left, right. Traverse the top row left-to-right, the right column top-to-bottom, the bottom row right-to-left, and the left column bottom-to-top, shrinking each boundary inward after its pass — a direct layer-by-layer geometric traversal.

def spiralOrder(matrix):
    res = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    while top <= bottom and left <= right:
        for c in range(left, right + 1):
            res.append(matrix[top][c])
        top += 1
        for r in range(top, bottom + 1):
            res.append(matrix[r][right])
        right -= 1
        if top <= bottom:
            for c in range(right, left - 1, -1):
                res.append(matrix[bottom][c])
            bottom -= 1
        if left <= right:
            for r in range(bottom, top - 1, -1):
                res.append(matrix[r][left])
            left += 1
    return res

Time O(m·n) · Space O(1) extra (excluding output)

HARD

Max Points on a Line

LC 149

Given points on a 2-D plane, find the maximum number of points that lie on the same straight line.

Why this pattern — A geometry problem solved combinatorially: for every point, compute the slope to every other point as a reduced-fraction key (avoiding floating-point error) and hash points by shared slope. The largest bucket for any anchor point is the most collinear points passing through it — take the max across all anchors.

def maxPoints(points):
    n = len(points)
    if n <= 2:
        return n
    best = 1
    for i in range(n):
        slopes = collections.defaultdict(int)
        for j in range(n):
            if i == j:
                continue
            dx = points[j][0] - points[i][0]
            dy = points[j][1] - points[i][1]
            if dx == 0:
                key = ('inf',)
            else:
                g = math.gcd(dx, dy)
                dx, dy = dx // g, dy // g
                if dx < 0:
                    dx, dy = -dx, -dy
                key = (dx, dy)
            slopes[key] += 1
            best = max(best, slopes[key] + 1)
    return best

Time O(n²) · Space O(n)
